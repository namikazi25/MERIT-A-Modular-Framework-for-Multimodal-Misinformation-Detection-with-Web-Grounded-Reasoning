- Headline verifiably false (Q/A contradicts)
- Image is AI-generated (ai_generated=true, confidence>0.6)
- Image completely wrong (aligned=false)
→ Classify as Misinformation

STEP 2 - Evaluate partial alignment cases:

High confidence partial (≥0.7):
- Interpretation: Right subject, incomplete details visible
- If headline true AND image genuine → Not Misinformation

Low confidence partial (<0.7):
- Interpretation: Possibly wrong subject, superficial match
- If headline true AND image genuine → Misinformation (likely mismatch)

STEP 3 - Verify genuine content (ALL required):
- Headline accurate (Q/A supports)
- Image genuinely relates (aligned=true OR partial with confidence≥0.7)
- Image authentic (ai_generated=false)
→ Not Misinformation
